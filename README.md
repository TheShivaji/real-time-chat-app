# ⚙️ Installation

Clone repository

```bash
git clone https://github.com/yourusername/mern-realtime-chat-app
```

Enter project

```bash
cd mern-realtime-chat-app
```

Install dependencies

```bash
npm install
```

Run project

```bash
npm run dev
```

---

# 🔐 Environment Variables

Create `.env`

```env
PORT=5000
MONGO_URI=your_mongodb_url
JWT_SECRET=secret
```
